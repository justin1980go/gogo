啟用全台線上查詢

設定一次，之後就能從網頁輸入城市、行政區或景點查詢，不必逐一加資料。此版本不提供檔案下載。

程式已備妥，但尚未設定你的 Google 金鑰或部署 Worker，所以目前還不能取得真實查詢結果。

1　建立 Google 地點資料服務

  1. 登入 Google Cloud Console，建立一個專案，例如「台灣旅遊規劃室」。
  2. 為該專案連結帳單帳戶。在 API 程式庫搜尋並啟用 Places API (New)。
  3. 在 API 和服務的憑證頁建立 API 金鑰，API 限制僅允許 Places API (New)。這是伺服器金鑰，不要設定為只接受瀏覽器 HTTP referrer。
  4. 設定 API 配額與預算通知。預算通知不是自動停止扣款的上限；費用依實際請求與 Google 當期計價。

金鑰不要貼進對話、config.js 或 GitHub，下一步會直接存入 Cloudflare Secret。

2　部署 Cloudflare Worker

建立 Cloudflare 帳號，電腦安裝 Node.js 24。在完整專案資料夾開啟 PowerShell，執行：

npx wrangler login
npx wrangler deploy --config worker/wrangler.jsonc
npx wrangler secret put GOOGLE_PLACES_API_KEY --config worker/wrangler.jsonc

最後一個命令會要求輸入金鑰，貼入剛建立的 Google 金鑰。記下部署回傳的 Worker 網址，例如 https://taiwan-travel-studio-api.你的子網域.workers.dev。

worker/wrangler.jsonc 已包含每個來源 IP 每分鐘各 5 次規劃與餐宿請求的流量限制。請使用 Wrangler 4.36.0 以上；namespace_id 應避免與同帳號其他 Worker 共用。

3　填入網頁設定並在本機驗收

將 public/config.js 改成以下內容，只填 Worker 網址：

window.TRAVEL_CONFIG = {
  apiBase: "https://taiwan-travel-studio-api.你的子網域.workers.dev"
};

雙擊「啟動旅遊規劃室.cmd」，或執行 npm run build、npm run dev 後開啟 http://127.0.0.1:4173。依序試「台中」「花蓮」「日月潭」；只有畫面真的回傳地點才算連線成功。

直接雙擊 index.html 只能查看介面與設定提示。全台查詢需要 HTTP／HTTPS 網站，請不要將 null 加入 Worker 允許來源。

4　發布 GitHub Pages

  1. 在 worker/wrangler.jsonc 的 ALLOWED_ORIGINS 加上正式網站來源，例如 https://你的帳號.github.io；不要加儲存庫子路徑，多個來源用逗號分隔。
  2. 重新執行 Worker deploy。建立 GitHub 儲存庫，上傳原始碼，不要上傳 .dev.vars、.env 或金鑰。
  3. GitHub Settings → Pages → Source 選 GitHub Actions。推送 main 或手動執行隨附的 Publish travel studio 工作流程；發布目錄為 web-dist。
  4. 在正式網址測試城市、指定景點、無結果與手機版。這一步完成後，日常使用不需啟動電腦上的程式。

查詢會顯示什麼

搜尋地點周邊約 15 公里的候選景點，依日期、交通預留與步調產生 1–5 天行程，提供室內雨備、地址、營業資訊、可取得的實景照片及 Google Maps 導航。搜尋結果不足、同名地點或場館休館時需調整查詢，不保證每個輸入都有可行行程。

每次規劃最多 5 次地點搜尋及 12 次照片請求；規劃後自動查詢本日餐宿，另需最多 2–3 次搜尋；日期或雨備的餐宿條件改變時重新查詢，同條件於本次頁面重用結果。照片失敗會保留行程並提示。沒有天氣預報、導航車程或餐廳訂位；未知營業時間與票價會註明，資料分類為室內也不代表已確認雨天營業。

美食與住宿推薦

午餐與晚餐各最多兩家旅客評分 4.5 分以上餐廳，距參考景點 3 公里內。晚餐為末站附近候選，尚未加入返程時程與預算。

多日每晚推薦末站周邊 15 公里內的官方三星以上飯店及旅客評分 4.5 分以上民宿，最後一天不推薦過夜住宿。飯店星級來自交通部觀光署旅館民宿開放資料，依政府資料開放授權條款第1版提供，資料日期顯示於結果。更新名冊可執行 scripts/update-hotels.py 後重新部署 Worker。

推薦不代表當日空房、可訂位或已查價。星級與旅客評分是不同標準。評分資料會增加 Google 查詢計費級別。

使用條款與隱私

本頁提供候選行程資訊，不代訂餐廳或票券。請核對當日公告與實際路線。線上地點與照片由 Google Maps 提供，使用時適用 Google 服務條款與Google 隱私權政策。

你的旅遊條件會傳給自行部署的 Cloudflare Worker；只有目的地與搜尋範圍傳給 Google Places，不會把同行人數、預算或出發地傳給 Google。本程式不建立帳號、不保存旅遊紀錄，不將地點與照片結果寫入本機儲存或資料庫。照片與字體載入可能直接連線到供應商；平台仍可能產生必要服務紀錄。公開營運前請補上管理者聯絡方式。
